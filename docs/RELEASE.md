# OmniCast 2.1.0 Preview

- **Desktop builds** for Intel macOS, Windows x64, and Linux x64. Extract the full archive, then open OmniCast. The builds include Android Debug Bridge and official scrcpy 5.0.1.
- **Mobile build** for ARM Android 8+. The debug APK is an Android controller for USB OTG and wireless pairing. It uses its own matched scrcpy client and server.
- **Desktop Android controls** include a customizable pad, three-button navigation, virtual keyboard and dial pad, toggleable notifications, and Quick Settings shortcuts.
- **ADB tools** include an interactive device shell, recovery and diagnostic actions, screenshot export, and a searchable command guide.
- **Wireless manager** discovers local ADB services, pairs by six-digit code or QR, and manages connection addresses.
- **Settings** include opt-in keep awake, screen-off mirroring, game input, video quality, hardware or software decoding, and reconnect preferences. Advanced capture offers virtual displays and a Linux webcam sink.

Download and compare the SHA-256 checksums if needed. [Validation notes](https://github.com/sabbirimon/OmniCast/blob/main/docs/STATUS.md)
